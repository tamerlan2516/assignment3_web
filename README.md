## Task 0 - Responsive Typography

I created a heading and paragraph. CSS Media Queries change the font size for desktop, tablet and mobile screens.

## Task 1 - Responsive Layout with Media Queries

I created three boxes. On desktop they are displayed in one row. On tablet they are displayed two per row. On mobile they are stacked vertically.

## Task 2 - Bootstrap Responsive Columns

I used the Bootstrap 12-column grid. The three columns use `col-lg-4`, `col-md-6` and `col-12` so they change their layout depending on screen size.

## Task 3 - Bootstrap Navigation Bar

I created a Bootstrap navigation bar with a logo and three links. On smaller screens the links collapse into a hamburger menu.

## Task 4 - Responsive Portfolio

I created a portfolio page with a Bootstrap navbar, project cards on the left, personal information on the right, and a footer. Bootstrap Grid and CSS Media Queries are used together.

## Work Summary

I created the webpage using HTML, CSS Media Queries and Bootstrap. I used Media Queries for responsive font sizes and the box layout. I used Bootstrap Grid for the columns, navigation and portfolio. The page is designed to work on desktop, tablet and mobile screen sizes.
